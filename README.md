# SMB Enumerator

A simple Python tool for enumerating SMB services using Nmap.

## Features

* SMB port detection
* SMB protocol enumeration
* SMB OS discovery
* SMB share enumeration

## Requirements

* Python 3
* Nmap

## Usage

```bash
python SMB_Enumerator.py
```
